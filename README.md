# HAIL-DSS
Human AI Life Decision Support System is a team project developed to assist users in making better decisions through AI-driven analysis and personalized recommendations.The system leverages machine learning techniques to reduce cognitive bias,evaluate options,and provide data-driven insights for effective decision-making.
Features
-AI-powered recommendations
-Decision analysis
-Risk assessment
-User-friendly interface
Technologies Used
-React.js
-Node.js
-Machine Learning
-MongoDB
